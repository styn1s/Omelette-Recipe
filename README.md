# 🥘 Omelette Recipe Page
A simple, responsive HTML/CSS page that shows you how to make a perfect classic omelette. This project is ideal for anyone looking for a quick recipe reference.

![Screenshot of the page](/images/screenshot-1.png)

![Screenshot of the page](/images/screenshot-2.png)

## ✨ Features
- Clear Instructions: Step-by-step guide to making a basic omelette.

- Customization Options: Suggestions for fillings like cheese, vegetables, and meats.

- Clean Design: A visually appealing, easy-to-read layout.

- Responsive: Works on both desktop and mobile devices.

## 🚀 Live Demo
You can view the live page here: https://styn1s.github.io/Omelette-Recipe/

## 🛠️ Technologies Used
- HTML5: For the page structure and content.

- CSS3: For styling and responsive design.
